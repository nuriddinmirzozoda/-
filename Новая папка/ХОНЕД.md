# Табрикнома барои Самиаллоҳ — дастур

## Чӣ гуна кор мекунад

Ҳамин ки корбар линкро кушод, чор парда яке паси дигар меоянд:

1. **Конверт** — 1,4 сония баъди кушодани саҳифа худаш кушода мешавад, салют меборад
2. **Мактуб** — матн ҳарф ба ҳарф навишта мешавад (тугмаи «Зудтар» барои гузаштан)
3. **Аксҳо** — 10 акс бо 5 навъи анимация, худкор иваз мешаванд
4. **Табрикоти охирин** — матни кӯтоҳ ва салют

Ҳеҷ чиз пахш кардан лозим нест — ҳамааш худаш меравад.

## Сохтори папка

```
tabriknoma/
├── index.html
├── css/style.css
├── js/config.js     ← ТАНҲО ҲАМИНРО ТАҒЙИР ДИҲЕД
├── js/main.js
└── images/          ← аксҳо ба ҳамин ҷо
```

## Аксҳо

Даҳ аксро ба `images/` монед бо номҳои `1.jpg` … `10.jpg`.
Агар формат дигар бошад — дар `js/config.js` рӯйхати `photos`-ро ислоҳ кунед.
Аксҳои уфуқӣ беҳтар мешинанд; ҳаҷми ҳар як то ~500 КБ.

Ҳар акс анимацияи худро мегирад, ба навбат:
наздикшавӣ → дуршавӣ → ҳаракати уфуқӣ → ҳаракати амудӣ → фокус аз хира ба равшан.

## Танзимот дар `js/config.js`

| Калид | Маънӣ |
|---|---|
| `name`, `from` | номи дӯст ва номи шумо |
| `birthDate` | санаи таваллуд, шумораи рӯзҳо худаш ҳисоб мешавад |
| `turning` | ба кадом синну сол қадам мегузорад |
| `letter` | матни мактуб, ҳар сатр як параграф |
| `finale` | табрикоти охирин |
| `typeSpeed` | суръати навиштани ҳарфҳо (кам = тезтар) |
| `slideDuration` | ҳар акс чанд миллисония |
| `music` | `false` — бе оҳанг |

## Оҳанг

Браузерҳо садоро то аввалин ламси экран намемонанд — ин қоидаи худи браузер
аст. Ҳамин ки корбар як бор ба экран даст расонад, оҳанг сар мешавад.
Тугмаи нота дар кунҷи рост барои хомӯш/фаъол.

## Нашр кардан (барои линк фиристодан)

1. **Netlify Drop** — netlify.com/drop, папкаро бо муш кашед, тамом
2. **GitHub Pages** — репозиторий → Settings → Pages
3. **Vercel** — ҳамин тавр

Баъди нашр дар `index.html` сатри `og:image`-ро ба линки пурраи акс иваз
кунед, то дар Телеграм пешнамоиш зебо барояд.

## Идора

- Чап/рост дар телефон — акси дигар
- ← → дар клавиатура — акси дигар
- Enter ҳангоми навиштани матн — зудтар
- Тугмаи «Аз нав» дар охир — ҳама чиз аз сар
